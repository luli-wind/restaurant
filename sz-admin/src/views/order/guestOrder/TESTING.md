# 访客下单功能测试指南

## 测试准备

1. 确保后端服务已启动并正常运行
2. 确保数据库中有菜品数据
3. 确保网络连接正常

## 测试步骤

### 1. 访问测试页面
- 在浏览器中打开测试页面: `/order/guestOrder/testPage`

### 2. 测试菜品列表
- 查看页面是否正确显示菜品列表
- 检查菜品图片、名称、价格和描述是否正确显示

### 3. 测试添加到购物车
- 点击任意菜品，检查是否能正确添加到购物车
- 检查购物车中菜品数量和总价是否正确计算
- 尝试多次点击同一菜品，检查数量是否正确累加

### 4. 测试订单表单
- 填写客户姓名、电话、配送地址和备注
- 检查表单验证是否正常工作（如电话号码格式验证）

### 5. 测试提交订单
- 点击"提交测试订单"按钮
- 检查控制台是否输出正确的订单数据
- 检查是否弹出订单提交成功的提示

## 预期结果

1. 页面能正常加载并显示菜品列表
2. 购物车功能正常，能正确添加、计算和显示菜品
3. 订单表单能正确收集用户信息
4. 订单能成功提交并在控制台显示正确的数据结构

## 常见问题排查

1. 如果菜品列表无法显示，请检查：
   - 后端API是否正常工作
   - 网络连接是否正常
   - 控制台是否有错误信息

2. 如果购物车功能异常，请检查：
   - 菜品添加逻辑是否正确
   - 价格计算是否正确
   - 数量更新是否正常

3. 如果订单提交失败，请检查：
   - 表单数据是否正确收集
   - API调用是否正常
   - 后端是否正确处理订单数据

## 测试数据

这些数据可以在 `testData.ts` 文件中修改。
