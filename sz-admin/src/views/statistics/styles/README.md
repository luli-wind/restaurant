## 2. 设计规范

### 2.1 色彩规范
- 主色调：`#ff6b35` (橙色)

- 警告色：`#e6a23c` (橙色)
- 危险色：`#f56c6c` (红色)
- 信息色：`#409eff` (蓝色)

### 2.2 间距规范
- 卡片间距：`20px`
- 元素内边距：`15px`
- 元素外边距：`10px`
- 图表边距：`20px`

### 2.3 字体规范
- 标题字体大小：`18px` 加粗
- 正文字体大小：`14px`
- 指标数字字体大小：`24px` 加粗
- 图表标签字体大小：`12px`

## 3. 响应式设计

### 3.1 断点设置
- 大屏幕：`≥ 1200px`
- 中等屏幕：`768px - 1199px`
- 小屏幕：`< 768px`

### 3.2 响应式规则
- 大屏幕：4列指标卡片布局
- 中等屏幕：2列指标卡片布局
- 小屏幕：1列指标卡片布局
